## Description
Evelar is a decentralized ticketing platform built on the blockchain. The platform allows users to seamlessly create and list events, and attend events on the platform. Our platform enables organizers to mint NFTs in the form of POAPs for registrants after each event. The platform instantly allows organizers to fetch event details after each creation.

## Features
Our platform is built on the Arbitrum blockchain, leveraging the scalability and decentralization of Arbitrum (L2). The contract is written in Rust (a WASM-based program), which is faster than the standard EVM L2 contract language and takes up less space for the same logic. The frontend is built using Next.js, providing a seamless connection with the smart contract.

Our solution is built on the blockchain to create an unalterable record. In traditional applications (Apps), the platform owner can decide to remove an event or bar an organizer or user from accessing the platform. However, our platform ensures that anyone, regardless of their identity, can create events.

## Smart Contract
Our smart contract is built on the Ethereum blockchain using Arbitrum Stylus. By leveraging smart contracts, the platform ensures trust, transparency, and accountability by recording all event creations and attendee registrations on the blockchain.

Evelar allows users to:

- Create events
- Register for events
- Get a refund
- Mint an NFT for attendees
- Withdraw the amount paid by attendees
